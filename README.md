# 🚫 تطبيق تسجيل الإلغاءات

تطبيق مصغر لتسجيل إلغاءات الطلبات في فروع المطاعم.

## المميزات
- واجهة صغيرة 160×280 تشتغل دايماً بالمقدمة
- تسجيل رقم الأوردر + رقم الزبون + الفرع + سبب الإلغاء
- نسخ الرسالة تلقائياً للإرسال عبر واتساب
- حفظ كل الإلغاءات محلياً
- تقرير يومي مفصّل مع فلتر حسب الفرع
- تصدير التقرير الكامل دفعة واحدة

## الاستخدام
1. افتح `index.html` في المتصفح
2. صغّر النافذة لحجم 160×280 وضعها بالزاوية
3. سجّل الإلغاء واضغط **حفظ + نسخ للواتساب**
4. الصق في واتساب وأرسل للمشرف
5. لعرض تقرير نهاية اليوم اضغط **فتح التقرير**

## الفروع المدعومة (12 فرع)
الشعب - البنوك - الغدير - الحرية - الدورة - بسماية - الغزالية - الأعظمية - حي العامل - البوعيثة - حي الجهاد - شهداء البياع

## أسباب الإلغاء
زبون | تكرار | تحويل | عدم رد | خارج الزون | مخصص
